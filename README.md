---

## 📌 Portfolio Structure & Projects

### 1. 🏢 Automated Real Estate Lead Extractor (`01_real_estate_scraper`)
- **The Problem:** Real estate agencies waste hours browsing listing portals manually to find underpriced investment opportunities.
- **The Solution:** A robust script that bulk-extracts titles, prices, currencies, locations, and direct links from public real estate marketplaces.
- **The Deliverable:** Automatic generation and download of a clean, structured **Excel (.xlsx)** file ready for financial analysis or cold outreach.

### 2. 📉 Competitor Price Monitor (`02_price_monitor`)
- **The Problem:** E-commerce stores need to react quickly to competitor price adjustments to avoid losing sales.
- **The Solution:** An intelligent bot that tracks specific product URLs, logs local cost histories, and executes change-control logic.
- **The Deliverable:** An automated system demonstrating discount alerts and price variation reporting simulated in real time.

### 3. 🧠 AI-Powered Customer Review Analyzer (`03_ai_review_analyzer`) *(In Development)*
- **The Problem:** Manually reading hundreds of client comments is highly inefficient for measuring user satisfaction trends.
- **The Solution:** Integration of data pipelines with Large Language Models (LLMs) to fully automate user sentiment audits.
- **The Deliverable:** Automatic sentiment classification and extraction of critical business pain points into analytical reports.

## 🚀 How to Run the Projects
Since this entire portfolio is optimized to ensure absolute portability and zero local resource consumption (ideal for any hardware setup), you don't need to install local environments:
1. Open the `.ipynb` files directly within GitHub's interface.
2. Click the **"Run in Google Colab"** badge available at the top of each project file.
3. Configure your basic input variables and run the cloud cells. The resulting output files will download straight to your computer automatically!

# 🚀 Python Automation & Data Solutions Portfolio

## 🛠️ Stack Tecnológico Global

- **Extracción de Datos & Scraping:** BeautifulSoup4, Requests
- **Procesamiento & Análisis de Datos:** Pandas, OpenPyXL
- **Entorno de Ejecución:** Google Colab (Cloud Infrastructure / Arquitectura Independiente)

---

## 📌 Estructura del Portafolio y Proyectos

### 1. 🏢 Extractor Automático de Leads Inmobiliarios (`01_real_estate_scraper`)
- **Problema:** Las agencias inmobiliarias pierden horas buscando publicaciones manualmente para encontrar oportunidades de negocio.
- **Solución:** Un script que extrae de forma masiva títulos, precios, monedas, ubicaciones y enlaces directos desde portales inmobiliarios públicos.
- **Entregable:** Generación y descarga automática de un archivo estructurado en **Excel (.xlsx)** listo para su análisis financiero o telemarketing.

### 2. 📉 Monitor de Precios de la Competencia (`02_price_monitor`)
- **Problema:** Los comercios electrónicos necesitan reaccionar rápido a los cambios de precios de sus competidores para no perder ventas.
- **Solución:** Un bot inteligente que analiza productos específicos, registra su historial de costos locales y ejecuta una lógica de control de cambios.
- **Entregable:** Sistema automatizado de alertas de descuento y reportes de variación de precios simulado en tiempo real.

### 3. 🧠 Analizador de Reseñas de Clientes con IA (`03_ai_review_analyzer`) *(En Desarrollo)*
- **Problema:** Analizar manualmente cientos de comentarios de clientes es ineficiente para medir la satisfacción del consumidor.
- **Solución:** Integración de procesamiento de datos con Modelos de Lenguaje (LLM) para automatizar la auditoría de satisfacción.
- **Entregable:** Clasificación automática de sentimiento y extracción de puntos críticos de mejora del negocio en reportes analíticos.
